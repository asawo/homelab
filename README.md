# Homelab

Configuration and environment files for my homelab services.

## Services

- **Proxmox** — Hypervisor and VM management
- **Immich** — Self-hosted photo/video management
- **Pi-hole** — Network-wide ad blocking and DNS

## Sensitive files

All `.env` files, secrets, keys, and credentials are excluded via `.gitignore`. Use `.env.example` files as templates.
